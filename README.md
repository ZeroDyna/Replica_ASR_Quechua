# Replica_ASR_Quechua

El proyecto busca estudiar e implementar modelos de ASR para el reconocimiento del habla en quechua, utilizando como fuente de datos el corpus de Common Voice correspondiente al quechua de Puno.

Se busca comprender el funcionamiento de los modelos utilizados, reproducir experimentos y analizar sus resultados.

## Corpus

Common Voice: corpus de grabaciones de voz y sus correspondientes transcripciones, utilizado para trabajar en el reconocimiento automático del habla en quechua de Puno.
